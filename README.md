# Portfolio de Mélysane LANTONKPODE

## 🚀 Développeuse Full Stack Web et Logicielle

Bienvenue dans mon portfolio personnel ! Ce site présente mes compétences, mes projets et mon parcours en tant que développeuse.

## 📋 Contenu

- **Accueil** : Présentation générale avec effet de frappe animé
- **À Propos** : Mon parcours et mes informations personnelles
- **Compétences** : Mes technologies et niveaux de maîtrise
- **Projets** : Mes 5 projets principaux avec détails
- **Contact** : Formulaire de contact et liens sociaux

## 🎨 Fonctionnalités

✨ **Design Moderne** :
- Animations fluides et professionnelles
- Effets de particules interactifs
- Design responsive (mobile, tablette, desktop)
- Palette de couleurs gradient moderne

🎭 **Animations** :
- Effet de frappe pour le titre
- Animation des barres de compétences
- Effets de hover sur les cartes de projets
- Scroll reveal pour les sections
- Morphing de l'image de profil
- Parallax sur certains éléments

📱 **Responsive** :
- Menu hamburger pour mobile
- Layout adaptatif pour toutes les tailles d'écran
- Optimisé pour tablettes et smartphones

## 🛠️ Technologies Utilisées

- **HTML5** : Structure sémantique
- **CSS3** : Animations et styles modernes
- **JavaScript** : Interactivité et animations
- **Particles.js** : Effet de particules animées
- **Font Awesome** : Icônes
- **Google Fonts** : Police Poppins

## 📦 Installation

1. **Dézipper le fichier** :
   - Extraire le contenu du fichier `portfolio-melysane.zip`

2. **Ouvrir avec un éditeur** :
   - Ouvrir le dossier avec VS Code, Sublime Text, ou votre éditeur préféré

3. **Lancer le site** :
   - Double-cliquer sur `index.html` pour ouvrir dans le navigateur
   - OU utiliser Live Server dans VS Code pour un rechargement automatique

## ✏️ Personnalisation

### Modifier vos informations :

1. **Texte** : Ouvrir `index.html` et modifier le contenu
2. **Couleurs** : Modifier les variables CSS dans `css/style.css` (ligne 7-15)
3. **Photos** : Remplacer les images dans le dossier `images/`
4. **Projets** : Modifier les liens GitHub dans la section projets

### Variables de couleurs (dans style.css) :

```css
:root {
    --primary-color: #6366f1;      /* Couleur principale */
    --secondary-color: #ec4899;    /* Couleur secondaire */
    --accent-color: #f59e0b;       /* Couleur d'accent */
}
```

## 🌐 Hébergement

Pour mettre votre portfolio en ligne :

1. **GitHub Pages** (Gratuit) :
   - Créer un repository GitHub
   - Uploader tous les fichiers
   - Activer GitHub Pages dans les settings

2. **Netlify** (Gratuit) :
   - Glisser-déposer le dossier sur netlify.com
   - Votre site sera en ligne en quelques secondes

3. **Vercel** (Gratuit) :
   - Connecter votre repository GitHub
   - Déploiement automatique
